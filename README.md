Homepage SHENRON.asi, a tool developed for Dragon Ball FighterZ: KAI to further expand the modding scenes capabilities. 

What is SHENRON? 
=
SHENRON is a memory editing tool which hooks directly to your RED-Win64-Shipping-eac-nop-loaded on launch. SHENRON then "catches" this information and edits it in various ways. The name comes from the idea that with this information, SHENRON can grant any wish we desire as long as we know the limitations (aka actually knowing the vtable addresses in game)

Installing SHENRON
=
Download SHENRON.asi and place the file within DBFZ's plugins folder. Typically it is located C:\Program Files (x86)\Steam\steamapps\common\DRAGON BALL FighterZ\RED\Binaries\Win64\plugins , however if you have DBFZ saved somewhere else in your computer you will need to place it within the plugins folder located there. That's it! SHENRON uses it's position as a plugin to run as the game launches!

Steam Lobbies
-
1. SHENRON creates a empty, hidden Steam Lobby upon launch of DBFZ. This lobby is completely separate from Ring Match Lobbies or any form of general online play and is simply used as a reference point for SHENRON to read regarding DBFZK. This allows us to have a player count of exactly how many people are on Kai as well as make sure that information sent is only given to players with SHENRON installed (to avoid any conflicts with official material). This is planned for much more in the future -such as having KAI players in a unique Casual Match queue so that finding players becomes even simpler - but for handles getting game information passed along between players in a simple manner.

Custom News Letter
-
1. The Latest News Announcer now receives Custom News Letters from the kai_news.txt. SHENRON scans for the newest news letter every hour and automatically updates it in game! Patch Notes will exist here alongside the changelog allowing players to see the latest updates as KAI continues to grow and develop

Custom Training Mode Options (WIP)
-
1. Currently work in progress, SHENRON will be gaining the ability to allow custom training mode options by emulating GGPO features while offline. The currently planned features are Save State / Load State done by replicating DBFZ's GGPO method of doing such in an offline matter, and hooking it to the Recording Slots within training mode. The ground work is already done, however it is currently disabled in SHENRON until it's fully completed.

About DBFZ: KAI
=
DBFZ: KAI is a full redux of modern DBFZ with a return to form of the design philosophy of older versions, while still retaining many of the new ideas brought in later iterations of the game. Alongside that, DBFZ:K welcomes many unique battle system changes for old and new players to experience alike! EVERY single aspect has been reviewed and adjusted, with many more updates to come!

Major changes include: 
Overall damage output reduced 
Variety in which meter can be spent greatly expanded 
Additional assist for all characters in the cast 
QoL fixes and changes 
And more!
